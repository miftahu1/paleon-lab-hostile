# Bounded resource stimuli

Every resource behavior has a dedicated hostname because the scanner fetches fixed paths and does not crawl links. Nginx must preserve streaming through public TCP 443: the normal proxy uses `proxy_buffering off` and `proxy_request_buffering off`, with a finite 660 second read timeout. The SNI stream proxy uses finite 660 second idle timeout. For public-path validation, the slow-drip fixture must deliver its first byte promptly and continue emitting increments rather than buffering until completion.

| Host | Behavior | Bound |
|---|---|---|
| `large-body.paleon-lab-hostile.com` | Stream generated bytes | default 10 MB, max 20 MB |
| `slow-body.paleon-lab-hostile.com` | Ten delayed 1 KB chunks | configurable delay capped at 15 seconds |
| `gzip-body.paleon-lab-hostile.com` | Gzip metadata/body probe | Paleon may inspect response metadata but does not decompress or expand response bodies; no decompressed-size limiter is exercised |
| `kill-test.paleon-lab-hostile.com` | Greeting, hold, close | 15 seconds |
| `slow-drip.paleon-lab-hostile.com` | One byte every 10 seconds | 60 bytes maximum / 10 minutes maximum |
| `slow-tls.paleon-lab-hostile.com` | Delayed TLS handshake | fixed finite fixture delay |

The public-boundary check reads the first byte promptly and a second byte after its ten-second interval over port 443, proving that data is incremental through the public proxy rather than delivered only after the response completes. Resource behavior, expected scanner termination, and evidence are recorded per test in `expected.yaml`. The deployment timeout is deliberately longer than the maximum drip duration but is not infinite.
